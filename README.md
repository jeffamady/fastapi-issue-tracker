# Fastapi Issue Tracker Project

## Quick Start

1. Clone repository
    ```bash
   git clone https://github.com/jeffamady/fastapi-issue-tracker.git
   ```

2. Install dependencies:
   ```bash
   uv sync
   ```

3. Run the application:
   ```bash
   cd app
   uvicorn main:app --reload
   ```

3. Access your API:
   - API endpoints: http://localhost:8000/check
   - Interactive docs: http://localhost:8000/docs
